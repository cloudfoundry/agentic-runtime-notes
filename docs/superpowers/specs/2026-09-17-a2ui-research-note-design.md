# A2UI Research Note Design

## Goal

Capture a sourced research note on A2UI as a declarative, cross-platform protocol for agent-generated user interfaces.

## Scope

Cover A2UI's JSON component descriptions, trusted client catalogs, incremental updates, data
model/actions, transport independence, renderers, and early-preview maturity. Assess CF
relevance for agent-facing application UIs, keeping rendering and security in the client while
CF hosts agents, gateways, and backends.

## Structure and evidence

Create `research/a2ui.md` with the required four sections and frontmatter. Use the A2UI
repository, README, architecture, specification/version material, and renderer documentation.
Distinguish the public-preview status from a ratified standard and label CF analysis as
proposed integration.

## Validation

Run Devbox validation and tests, inspect whitespace/staged files, commit the note and plan on
`research/a2ui`, push, and open a PR targeting `main` without unrelated artifacts.
